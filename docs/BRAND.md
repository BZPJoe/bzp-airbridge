# Brand kit

**BZP Airbridge** · Build your remote. Keep control local.

Horton Systems header branding, black/steel panels, chrome buttons, and cyan accents match the owner's UniFi Sentinel style. The new geometric mark combines a remote with radio arcs, not generated fan blades.

| Token | Color |
|---|---|
| Black / panel | #000000 / #0B1013 |
| Steel / chrome | #7C858B / #EEF1F2 |
| Cyan / pale cyan | #28CFFF / #9BEAFF |
| Green / amber | #45ED72 / #FFBD22 |

Editable assets: icon.svg, wordmark.svg, cover.svg, wiring.svg. PNG counterparts are portable exports. Cover dimensions: 1280×640. Preserve clear space and proportions.

python tools/build_ui.py embeds the current assets/UI. python tools/render_assets.py requires resvg-py and produces PNGs. Horton Systems branding remains its owner's property.
